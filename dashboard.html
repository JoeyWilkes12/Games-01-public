Dataset notes & exclusions
  • 148 rows with positive numeric scores and known strategy and board codes; none excluded.
  • Strategy names use the workbook’s code mapping; its “Full Name” field contains missing and malformed values.
  • No timestamps, moves, maximum tile, timing, or seed fields are present. Row order is not a timeline.
  • Notes are free text and incomplete; they cannot establish a win rate.
  • Run 146 has an unusual score of 11,525. It is retained as recorded and flagged for source verification.
  • The source notes refer to a separate iOS game; these are not benchmarks of this browser’s solver.
